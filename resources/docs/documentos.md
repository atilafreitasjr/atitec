# Documentos

## Onde ficam

Cada projeto tem uma seção **Documentos do projeto** com os arquivos que a ATITEC compartilha com você,
organizados por categoria:

| Categoria | Exemplos |
|---|---|
| **Contrato** | Contrato de desenvolvimento e aditivos |
| **Escopo** | Proposta comercial, especificações e planejamento |
| **Entrega** | Materiais de entrega, manuais e relatórios |
| **Outro** | Demais arquivos relacionados |

## Download

Clique no nome do documento (ou em **Baixar**) para baixar o arquivo. Aceitamos PDF, Word, Excel e
imagens.

> **Privacidade:** os arquivos ficam em área privada do sistema. O download só é liberado para o
> cliente vinculado ao projeto e para os documentos marcados como visíveis ao cliente. Notas e
> arquivos internos da ATITEC não aparecem no seu workspace.

Precisa de algum documento que não está listado? Peça pelas **Mensagens** ou pelos canais de contato.
